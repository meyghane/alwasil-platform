Objectif : Vérifier la conformité à la DA du projet.

Entrées : DIRECTION_ARTISTIQUE.md et pages.

Sorties : Écarts et corrections ciblées.

Procédure et règles : Lire la DA actuelle ; Al-Wasil : blanc, citron, noir, violet, Lucide, CSS inline ; pas de données fictives dans les maquettes publiques.

Erreurs possibles : Ancienne palette, image trompeuse, faux bouton.

Tests : Inspection responsive et navigation réelle.

Validation humaine : Changement de DA. Les autorisations explicites déjà données restent applicables.

Dans Al-Wasil, lire les contrats de [l’architecture](../../docs/AGENT_ARCHITECTURE.md) pour les noms de tables, la politique et les routes. Pour un autre projet, adapter ces paramètres avant toute mutation ; ne pas réutiliser les identifiants ou secrets d’Al-Wasil.
